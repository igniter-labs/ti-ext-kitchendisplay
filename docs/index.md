## Overview

The Kitchen Display System (KDS) extension provides a real-time digital solution for managing and displaying orders in a restaurant kitchen. Kitchen staff can view, organize, and update order statuses seamlessly, improving communication and operational efficiency.

## Quick Features

- Real-time order display with automatic updates
- Kanban board layout with customizable columns
- Order status management and wait time tracking
- On-hold functionality with dedicated pause button
- Flexible filtering by location, status, type, and category
- Responsive design optimized for kitchen environments
- Scroll position preservation during refreshes
- Complete order details modal
